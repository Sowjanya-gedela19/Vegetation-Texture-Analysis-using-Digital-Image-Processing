# Vegetation Texture Analysis using Digital Image Processing

## Overview
This project analyzes vegetation textures from satellite imagery using image segmentation and feature extraction techniques.

## Features
- Image segmentation
- Texture feature extraction
- Vegetation analysis
- Visualization of results

## Technologies Used
- Python
- OpenCV
- NumPy
- Pandas
- Matplotlib

## Project Structure
- main.py
- requirements.txt
- meta_data.csv
- sample_visualization.png

## Results
Analyzed vegetation textures using image segmentation and feature extraction techniques to identify and evaluate vegetation patterns from satellite imagery.
